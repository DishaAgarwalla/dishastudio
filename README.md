## ⚡ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/DishaAgarwalla/dishastudio.git
```

Go to the project folder:

```bash
cd dishastudio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
